# Мини-маркет — домашнее задание по React

Небольшой учебный проект: каталог товаров и UI-кит на **React + TypeScript + styled-components**.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно http://localhost:5173/).

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Что реализовано

- Светлая и тёмная темы через типизированный `DefaultTheme` и `ThemeProvider`.
- Начальная тема берётся из `localStorage`, а при первом посещении — из системной настройки `prefers-color-scheme`.
- Цвета находятся в `src/theme.ts`; компоненты используют только значения темы.
- UI-кит: `Button` (4 варианта, 3 размера, `loading` и `disabled`), `Badge`, `Card`, `Input`, `Grid`.
- Стилизация через `styled-components`, `createGlobalStyle`, `keyframes` и transient props (`$variant`, `$size`, `$muted`).
- Каталог из 8 товаров: поиск, фильтры категорий, добавление в корзину с короткой анимацией загрузки, пустое состояние.
- Адаптивная сетка товаров: 1 / 2 / 3 / 4 колонки в зависимости от ширины экрана.

**Примечание:** корзина демонстрационная: счётчик увеличивается, но отдельной страницы оформления заказа нет.

## styled-components против CSS Modules на этом проекте

В этом проекте `styled-components` удобен тем, что варианты кнопки зависят напрямую от её пропсов `variant` и `size`. Все цвета для светлой и тёмной темы находятся в двух объектах, поэтому компоненты не нужно переписывать при переключении темы. TypeScript проверяет названия токенов через типизированный `DefaultTheme`. В CSS Modules для вариантов кнопки пришлось бы создавать отдельные классы и выбирать их в JSX. Зато CSS Modules не требует библиотеки для вычисления стилей в браузере и обычно проще для статичных компонентов. Для небольшого учебного UI-кита я выбрал `styled-components`, потому что здесь удобно показать тему, варианты и состояние загрузки.
